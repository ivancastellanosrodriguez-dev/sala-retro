Llevarlo a la TV

  • Laptop a la TV con cable HDMI: es lo más fluido.
  • Fire TV o Android TV: abre esta página en el navegador Silk o TV Bro.
  • Chromecast: en Chrome, menú ⋮ › Transmitir › Transmitir pestaña. Tiene algo de retraso.

Controles

  • Control Bluetooth o USB (Xbox, PlayStation, 8BitDo): conéctalo y presiona un botón.
  • En la biblioteca: flechas o cruceta para moverte, A o Enter para jugar.
  • Durante el juego: mantén Select + Start dos segundos para volver.
  • Teclado: flechas, Z = A, X = B, Enter = Start.
