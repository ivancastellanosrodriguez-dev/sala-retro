# Sala Retro

Página para jugar tus propios juegos retro (NES, SNES, Game Boy, GBA, Sega, N64, PlayStation) en la TV, con un control Bluetooth/USB o con el celular como control.

- `index.html`: biblioteca y reproductor. Los juegos que agregas se guardan en el navegador.
- `control.html`: control táctil para el celular. Se abre escaneando el código QR de la página principal.
- `data/`: [EmulatorJS](https://github.com/EmulatorJS/EmulatorJS) 4.2.3 (GPL-3.0) con sus núcleos.
- `demo/prueba-control.nes`: juego de prueba propio; la pantalla se pone verde al presionar A.

No incluye juegos comerciales: usa los archivos de los juegos que tengas.
